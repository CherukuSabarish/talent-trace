📊 TalentTrace 2.0: send candidates to Google Sheets

One-time setup on a fresh Google Sheet, about 10 minutes. After this, Google X-ray results (LinkedIn, Stack Overflow, GitHub) and the app's own GitHub and TalentData results all go to the same Sheet. Back to Talent Trace

1 Put the TalentTrace 2.0 script in a new Google Sheet

This is the small program inside your Sheet that receives candidates and writes them as rows.

  1. Make a new blank Google Sheet (go to sheets.new) and give it a name, for example TalentTrace 2.0.
  2. In the Sheet's top menu click Extensions → Apps Script. A new tab opens with a file called Code.gs.
  3. Click this button to copy the script: Copied ✓
  4. In Code.gs, select everything that's there (Ctrl+A, or ⌘+A on Mac), delete it, and paste (Ctrl+V).
  5. Click the 💾 Save icon.

Then publish it:

  1. Click the blue Deploy button (top right) → New deployment.
  2. Click the ⚙️ gear next to "Select type" and choose Web app.
  3. Set Execute as: Me, and Who has access: Anyone.
  4. Click Deploy, then Authorize access and allow it with your Google account. If you see "Google hasn't verified this app", click Advanced → Go to … (unsafe). It's your own script, so this is expected.
  5. Copy the Web app URL. It starts with https://script.google.com/ and ends in /exec.

If you change the script later: Deploy → Manage deployments → ✏️ → Version: New version → Deploy. That keeps the same URL.

Check it worked: paste the URL in a new browser tab. You should see a short line of text that includes "app":"TalentTrace 2.0 Sheet".

Use a Google account that allows sharing with Anyone. Some company Google accounts only allow "Anyone in the company", and then the app and extension can't reach the Sheet. A personal Gmail account always works.

2 Save the new Sheet URL in Talent Trace

  1. Open Talent Trace → Sourcing → GitHub Search (or TalentData).
  2. Scroll down to Send to Google Sheet, delete the old URL in Google Sheet Apps Script URL, paste the new one, and click Save. Do the same on the other tab (TalentData or GitHub Search), so both send to the new Sheet.

You only do this once. The Chrome extension picks up the same URL from the app automatically.

3 Install the TalentTrace 2.0 Chrome extension

It adds a "Send to Google Sheet" box to Google results pages.

  1. ⬇ Download the extension
  2. If you still have the old TalentTrace — X-Ray Exporter (v1.6) extension, remove it first: go to chrome://extensions and click Remove on it.
  3. Open your Downloads folder and unzip talentrace-2.0-extension.zip (on Windows: right-click → Extract All; on Mac: double-click it). You get a folder called talentrace-2.0-extension. Keep this folder; Chrome loads the extension from it, so don't delete it.
  4. In Chrome, type chrome://extensions in the address bar and press Enter.
  5. Turn on Developer mode (the switch in the top-right corner).
  6. Click Load unpacked and choose the talentrace-2.0-extension folder.
  7. Click the 🧩 puzzle icon in Chrome's toolbar and the 📌 pin next to TalentTrace 2.0, so its icon stays visible.
  8. Open or refresh the Talent Trace tab once. Under the Boolean Builder buttons you should see ✓ Extension connected.
  9. Optional check: click the TalentTrace 2.0 icon in the toolbar, then Test connection. It should say Connected with your Sheet's name.
Chrome may show a message about "developer mode extensions" when it starts. That's normal for extensions you load yourself; click the X to close it.

4 Use it

Google X-ray (LinkedIn, Stack Overflow, GitHub)

  1. In the Boolean Builder, pick a role, click ⚡ Generate Query, then click 🔍 Google X-Ray, StackOverflow or GitHub.
  2. On the Google page, a 📊 TalentTrace 2.0 box appears in the bottom-right corner. It has already collected the profiles on that page.
  3. Want more? Click Google's Next page (2, 3, …). Each page is added to the same list.
  4. Check the Role tag (it becomes the Sheet tab name; it's filled in from the role you picked), then click Send … to Google Sheet.

GitHub Search and TalentData in the app

  1. Search as usual. In GitHub Search's Repos mode, pull a repo's contributors into Candidates.
  2. At the bottom, set the Role tag and click 📊 Export All to Google Sheet.

Each role gets its own tab in the Sheet, and the Dashboard tab counts candidates by role, status and source. The Search Log tab lists every export. Use the Status dropdown (New, Contacted, Shortlisted, Rejected) and the Recruiter Notes column to track people. Exporting the same people again doesn't create duplicates: they're skipped and counted as "already there".
